# ABHAYA Backend

This folder contains the Node.js / Express backend for the ABHAYA Women's Safety Platform.

## Structure
- `src/controllers`: Request handlers for API routes.
- `src/models`: Mongoose database schemas.
- `src/routes`: Express routing definitions.
- `src/middleware`: Custom middleware (e.g., authentication).
- `src/server.js`: The main entry point.

## Running Locally
1. `npm install`
2. Configure your `.env` file based on `.env.example`.
3. `npm start`
